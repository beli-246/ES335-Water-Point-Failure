Baselines and methods

ModelWhy it fits this problemWhat we tune
Majority classThe floor: one score for every point, so PR-AUC = no-water rate.–
One-rule stumpThe single split with the highest information gain, the kind of rule a field office would write by hand. The baseline every model must beat.–
Logistic regressionLinear in log-odds and interpretable. Also implemented from scratch.C (L2 strength)
Decision tree (entropy)Handles mixed feature types and interactions; readable rules [Breiman et al. 1984].Cost-complexity α (pruning)
Random forestBagging plus random feature subsets average away the variance of deep trees [Breiman 2001].Minimum leaf size
XGBoostBoosting: each tree fits the previous trees' errors, reducing bias. Regularised by depth, child weight and L2 λ [Chen & Guestrin 2016].Depth, child weight, λ
Linear and RBF SVMMaximum-margin classifiers; the RBF kernel tests whether a curved boundary helps. Training cost grows roughly with n², so they use a 20,000-row stratified subsample. Platt scaling converts margins to probabilities [Platt 1999].C, γ
Stacked ensembleA logistic regression on the out-of-fold log-odds of the pooled and local models, so it learns how far to trust each one and recalibrates to the local no-water rate [Wolpert 1992].–

Choosing the final model without the test set

For each country, every candidate (5 models × regimes A and C, plus the stack) is scored by 5-fold grouped CV over that country's training districts. In each fold, the held-out districts are target-country districts, which is exactly what the test measures. The best CV score becomes the final model. All candidates are then scored on the test districts, and the table shows them all, but the test scores did not choose anything (src/final.py).
