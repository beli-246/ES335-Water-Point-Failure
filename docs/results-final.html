The final model per country

Sorted by cross-validation score; the highlighted row was chosen. Test columns were computed afterwards.

Calibration

When the model says 30%, are 30% of those points broken? The dashed diagonal is perfect calibration. Platt scaling is a one-feature logistic regression fitted on the model's out-of-fold predictions (training districts only). It is monotone, so the ranking and PR-AUC do not change; only the probabilities do.

Which inputs matter (permutation importance)

Shuffle one column across test points, re-run the full pipeline, measure the PR-AUC lost. A categorical counts once, however many dummy columns it has.

CV chose local random forest in Ethiopia, local logistic regression in Tanzania, and the stacked ensemble in Kenya and Uganda. In Tanzania, CV preferred logistic regression (0.657) over local XGBoost (0.644). On the test districts XGBoost turned out better (skill 0.34 vs 0.26), but the CV gap was far inside its own noise (±0.09). We report the CV choice anyway: picking the test winner would turn the test set into a validation set and make every reported number optimistic.

The stack's weights lean on the local models (local random forest +0.78 in Ethiopia, +0.80 in Uganda). Some weights are negative (local random forest −0.41 in Tanzania). That does not mean "this model is harmful": the base models are highly correlated, so the stacker uses differences between them. Stack weights are not feature importances.

Platt scaling fitted on out-of-fold predictions learned slopes of 0.84–1.08. A slope of 1 means "already calibrated", so it changed little. It slightly helped Tanzania (Brier 0.234 → 0.232) and slightly hurt Ethiopia (0.078 → 0.080). Calibration learned on training districts does not fully carry over to new districts; Tanzania's bins miss by about 8 points on average. We kept the rule we had fixed before seeing test results.

Permutation importance differs by country, which is more evidence against one model for every country. Technology, management, water source and age matter in Ethiopia. Age dominates in Tanzania, where the audit had already found it was the strongest single feature. Local population matters most in Uganda, partly through its 17.5% missingness (see ablations). Water source matters most in Kenya.
